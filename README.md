To use this app you need to get a free Spotify developer web api 
Spotify Developer Dashboard: https://developer.spotify.com/dashboard

To do get your credentials:
1. Open the Spotify Developer Dashboard and log in.
2. Click Create App. Enter an App name (e.g. What New Songs) and Redirect URI: http://127.0.0.1:8888/callback.
3. Check Web API and click Save.
4. In Basic Information, click View client secret and copy the Client ID and Secret here.
